# Generate a Combo (React + Vite)

## 🚀 One-click launch

| | Link |
|---|---|
| **Use online** | `https://YOUR-USERNAME.github.io/generate-combo-react/` |
| **Open in StackBlitz (runs in browser)** | `https://stackblitz.com/github/YOUR-USERNAME/generate-combo-react` |

> Replace `YOUR-USERNAME` with your GitHub username.

## Run locally

```bash
npm install
npm run dev
npm run build
```

Photos live in `public/image/`. If a photo is missing, an initials placeholder is shown.
